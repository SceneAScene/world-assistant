# World Assistant 1.0.0

**World Assistant** 是基于原 `world-backstage（世界背面）` 重构的 SillyTavern 第三方扩展。本仓库从 **1.0.0** 作为独立版本开始维护。

原项目：`https://github.com/h675786161-prog/world-backstage`

## 主要功能

### 世界推演
根据聊天正文、人物状态与已有世界信息维护后台世界状态，使未直接出现在当前场景中的人物和事件能够继续发展。

### 此刻
集中查看当前世界时间、运行状态、待处理任务及近期变化，是插件的总览页面。

### 人物
维护人物状态、位置、关系、行动与知识边界，并支持从世界书导入人物资料。

### 暗流
记录和推进尚未完全公开、仍在后台发展的事件线索与潜在事件。

### 回声
整理已经发生并对当前世界仍有影响的事件结果、后续影响与关联信息。

### 舆情
生成和维护公开世界中的新闻、论坛讨论、传闻等社会信息，用于表现事件在公共环境中的传播和反馈。

### 记忆
整理长期事实、人物记忆、事件摘要与持续有效的信息，减少长对话中重要背景丢失。

### 纪事
以时间顺序保存重要世界事件和阶段性变化，便于回顾剧情发展。

### 智能助手
原“玲七”助手能力保留并改造成中性的 **智能助手**。可用于查询插件状态、解释设置、执行部分管理操作、辅助故障诊断以及提供剧情引导。智能助手不再占用一级导航，而从界面顶部的 `AI` 入口打开。

### API 与模型
支持使用 SillyTavern 当前生成能力或自定义 API 完成后台推演，并保留原有模型、重试、输出控制等相关设置。

### 世界书与正文联动
可读取世界书人物信息，并根据设置把必要的世界状态、人物信息、记忆或舆情内容提供给后续生成流程。

### 快照与恢复
保留聊天状态快照、重抽恢复及相关保护机制，尽量避免重抽、切换消息或长时间使用时造成状态错乱。

## 本版本的界面调整

- 移除原“通讯”社交系统的用户入口、自动活动、正文注入及智能助手中的通讯操作。
- 原“玲七”改名为 **智能助手**，去除猫咪吉祥物和主要卖萌式说明。
- 智能助手从一级导航移出，减少移动端底部/侧边导航占用。
- 移除悬浮球入口及相关设置。
- 使用 **SillyTavern 魔法棒 / Extensions 菜单 → 世界背面**作为主要入口。
- 保留“此刻、人物、暗流、回声、舆情、记忆、纪事”等主要界面与功能逻辑。

## 安装

仓库上传到 GitHub 后，在 SillyTavern 的第三方扩展安装界面中使用本仓库地址安装。

安装完成后刷新 SillyTavern，然后从输入框附近的 **魔法棒 / Extensions 菜单**打开“世界背面”。

> 第一次使用建议先在测试聊天中验证 API、世界推演、人物状态、记忆和重抽恢复是否符合预期，再用于重要聊天。

## 兼容说明

为了降低旧聊天损坏风险，部分内部数据字段仍沿用原项目名称，例如 `lingqi` 或部分旧社交状态字段。这些名称属于内部兼容结构，不代表相应旧界面仍然存在。
